An assistant can give a convincing mathematical answer that is wrong. ProofDesk makes the answer checkable. This is a working mathematical MCP server with a simulated Alexa plus interface. Start with the Lyness recurrence and the guess x plus y. An exact counterexample shows that the guess changes. The corrected rational quantity is independently checked on its declared domain. Its receipt can be replayed by recomputing the same obligation. The other tools jump to a far future Fibonacci state using exact modular arithmetic, and inspect a sharp inequality with an equality witness. These are supported mathematical checks, not a claim that an assistant proves every theorem. The new MCP transport, interface, tools, and receipts build on our existing checking kernel. A separate open source MCP client makes the same tools usable from a small Python program. Every result leaves evidence a judge can inspect.
